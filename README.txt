ALETAI METEORITE — BILINGUAL MUSEUM DARK WEBSITE

Files:
- index.html: complete responsive single-page website (Vietnamese / English toggle).

Preview locally:
1. Extract the ZIP.
2. Double-click index.html to open it in Chrome, Edge, or Firefox.
3. Internet is needed for Google Fonts; all page structure and content are local.

Publish free with GitHub Pages:
1. Sign in to https://github.com and create a new PUBLIC repository, e.g. aletai-meteorite.
2. Upload index.html (and README.txt) to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
5. Wait for GitHub Pages to publish. Your public URL will look like https://YOUR-USERNAME.github.io/aletai-meteorite/ .
6. Open the URL on a phone using mobile data to confirm it is public.

QR CODE:
Create the final QR only AFTER publishing and confirming the permanent public URL.
Use any QR generator, paste the full https:// URL, download a high-resolution PNG or SVG, then test it on multiple phones before printing. Do not encode a temporary preview or local file path.

CONTENT / FACT CHECK NOTES:
- Meteoritical Bulletin lists Aletai as official; year found 1898; country China; recorded mass 74 t; recommended classification Iron, IIIE-an.
- The entry says the 74 t figure was revised on 3 Oct 2021.
- “Year found” is not the same as an observed fall date.
- Aletai is the official name for paired masses; former names include Armanty and Xinjiang (b).
- The Widmanstätten diagram on the page is schematic, not a photograph of a specific Aletai specimen.
- References are linked in the page itself.

Before exhibition use, review the bilingual copy and add credited/licensed specimen photographs if you have access to suitable images. The current hero and pattern graphics are original CSS illustrations, not documentary specimen photographs.
